# Web Kakeibo

## 概要

PythonとFlaskを使って作成しているWeb版の家計簿です。
支出の登録・表示・編集・削除ができます。

## 使用技術

- Python
- Flask
- HTML
- Git / GitHub

## 機能

- 支出の登録
- 支出の表示
- 支出の編集
- 支出の削除

## 学習目的

Pythonで作成した家計簿をWebアプリケーション化し、Webアプリケーションの基本的な仕組みを学ぶことを目的としています。

## ファイル構成

```text
Web-Kakeibo/
├── app.py
├── README.md
└── templates/
    ├── index.html
    └── edit.html
```

### 主なファイル

- `app.py`：Flaskの処理を記述
- `templates/index.html`：家計簿のメイン画面
- `templates/edit.html`：支出を編集する画面
